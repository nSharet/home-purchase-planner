# Home Purchase Planner

מחשבון ווב אינטראקטיבי ומפורט לתכנון רכישת בית, המבוסס על גרסת ה־HTML המקורית של הפרויקט ושומר את מלוא רמת הפירוט שלה.

## כניסה למחשבון

[פתיחת מחשבון תכנון רכישת הבית ב־GitHub Pages](https://nsharet.github.io/home-purchase-planner/)

## מה המחשבון כולל

- מספר תרחישים נפרדים, שכפול, מחיקה והשוואה ביניהם.
- מחיר נכס, סוג רכישה, שווי שמאי, תאריך עסקה ומגבלת LTV ניתנת לעריכה.
- מס רכישה אוטומטי לפי מדרגות המוגדרות בקוד או סכום ידני מהסימולטור הרשמי.
- תיווך ועורך דין באחוזים, עם אפשרות להוסיף מע״מ בנפרד.
- שמאות, משכנתא, אגרות, מעבר והוצאות עסקה נוספות.
- טבלת שיפוצים מפורטת ופתוחה: צנרת, מטבח, רחצה, סניטריה, חשמל, גמר, מערכות, נגרות, אבזור, עיצוב וריהוט.
- רזרבה לחריגות שיפוץ.
- הון עצמי נזיל, מקורות נוספים, רזרבת מזומן והון נטו מנכס קיים.
- טבלת מדרגות משכנתא והחזר חודשי עם אינטרפולציה או עיגול למדרגה הבאה.
- חישוב עלות כוללת, משכנתא נדרשת, החזר חודשי, LTV ופער מול מגבלת המימון.
- ניתוח רגישות של מחיר הבית והשוואת כל התרחישים.
- **מעבדת החלטה** לבדיקת מחיר בית חלופי ולחישוב מחיר בית מרבי לפי החזר חודשי יעד.
- שמירה אוטומטית בדפדפן, ייצוא/ייבוא JSON, הורדת JSON, CSV, העתקת סיכום והדפסה ל־PDF.

## עבודה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. לבדיקות:

```bash
npm test
```

## מבנה הפרויקט

- `index.html` — הממשק המלא.
- `src/app.js` — מצב האפליקציה, תרחישים, טבלאות עריכה, סיכומים, רגישות וייצוא.
- `src/calculator.js` — מנוע חישוב טהור ונפרד, המשמש גם את הבדיקות.
- `tests/calculator.test.mjs` — בדיקות נוסחאות, מימון, מס והחזר.
- `tests/html-structure.test.mjs` — בדיקת רגרסיה שמוודאת שהרובריקות והיכולות המרכזיות אינן נעלמות.
