# Home Purchase Planner

מחשבון ווב אינטראקטיבי לתכנון עלות רכישת בית: מחיר הנכס, מס רכישה משוער, תיווך, עורך דין, שיפוץ, הון עצמי, פער מימון, גודל משכנתא והחזר חודשי.

## יכולות
- עריכת כל פרמטרי העסקה וההון הזמין.
- רשימת הוצאות שיפוץ ועיצוב הניתנת להרחבה.
- מדרגות אישיות של משכנתא והחזר חודשי.
- שמירה מקומית בדפדפן.
- ייצוא וייבוא JSON וייצוא סיכום CSV.
- בדיקת חריגה משיעור המימון שהוגדר.
- בדיקות יחידה אוטומטיות ופרסום ב-GitHub Pages.

## עבודה מקומית
פתחו את `index.html` בדפדפן, או הפעילו שרת סטטי מקומי. לבדיקות:

```bash
npm test
```

## GitHub Pages
לאחר מיזוג ל-`main`, workflow בשם **Deploy GitHub Pages** בונה ומפרסם את האתר. בפעם הראשונה ייתכן שצריך לבחור ב-Settings → Pages → Source: GitHub Actions.

## ניהול העבודה
שינויים עתידיים ינוהלו דרך Issues ו-Pull Requests. מומלץ לפתוח Issue לכל שינוי, ליצור branch ייעודי ולהפנות אליו מה-PR.

## הערה משפטית
החישובים הם כלי תכנון בלבד. מדרגות מס, מגבלות מימון ועלויות עסקה עשויות להשתנות, ולכן יש לאמת אותן מול רשות המסים, הבנק ואנשי המקצוע.
